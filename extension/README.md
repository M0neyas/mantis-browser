# Vestavěné rozšíření Mantis

Při buildu se zabuduje přímo do prohlížeče (`browser/extensions/mantis`,
v `omni.ja` jako `builtin-addons/mantis/`) a Firefox ho nainstaluje sám.
Nejde odinstalovat, v `about:addons` je vidět jako „Mantis“.

| Soubor | Co dělá |
|---|---|
| `newtab/` | nová karta: logo, hodiny a datum, jemné zelené pozadí, vyhledávání (výchozí vyhledávač), nejnavštěvovanější stránky, upozornění na novou verzi, ozubené kolo → Nastavení Mantis |
| `welcome/` | **uvítací stránka** při prvním spuštění (`runtime.onInstalled` → `install`, počká na první okno) a z Nastavení Mantis: co už funguje, přepínač šifrovaného DNS (výchozí vypnuto), **doporučená rozšíření** – „Přidat“ otevře stránku na addons.mozilla.org, nic se neinstaluje samo (pravidlo Storu 10.1.5); stav přes `mantisPrefs.addonsInstalled` |
| `settings/` | **Nastavení Mantis** (`options_ui`; z nové karty nebo about:addons): obraz v obraze při přepnutí karty, automatické přehrávání, plynulé rolování, WebGL (Zabezpečení), kill switch VPN, hodiny/pozadí nové karty, zapomenout web, jiný prohlížeč, choulostivé stránky, šifrované DNS, co jde přes VPN, synchronizace, aktualizace |
| `forget.js` | „Zapomenout web …“ v kontextové nabídce stránky a karty (Firefoxí `ForgetAboutSite` – historie, cookies, cache, data, oprávnění celé domény) |
| `sensitive.js`, `sensitive/` | **Choulostivé stránky**: navštívené stránky ze seznamu se hned mažou z historie (`history.onVisited` → `deleteUrl`) a z nedávno zavřených karet/oken (`sessions.forget*`). Kategorie „Pro dospělé“ = `sensitive/adult-domains.txt` (generuje `scripts/update-sensitive-list.sh`, MIT) + klíčová slova v hostname; vlastní weby, výjimky, úklid dosavadní historie; kontextová nabídka „Neukládat web do historie“. Nastavení v `storage.local` → `sensitive` |
| `experiments/` | privilegované API `mantisPrefs` (vestavěná rozšíření smí): čtení/změna **jen vyjmenovaných** nastavení, zapomenutí webu, spuštění staženého instalátoru (jen `Mantis-Browser-Setup*.exe` ze složky pro stahování a jen se sedícím SHA-256), `isPackaged` (běh z MSIX → bez vlastních aktualizací), `ensureVpnHost` (registrace VPN pomocníka pro zip a MSIX), `listBrowsers` / `openInBrowser` (jiné prohlížeče z registru `Clients\StartMenuInternet`; spustí se jen prohlížeč z tohoto seznamu a jen s http(s) adresou jako jediným argumentem) |
| `performance.js` | **Výkon** (Nastavení Mantis → Výkon, výchozí vše vypnuto, jen místně): *omezení paměti* – nad limitem uspí nejdéle nepoužívané karty na pozadí (pravidla jako `tabsleep.js`), *omezení CPU* (experimentální) – tvrdý strop pro procesy webů přes Job Object Windows (`mantisPrefs.setCpuLimit`, js-ctypes), *omezení sítě* – stahování přes `NetworkThrottleManager` z DevTools, odesílání přes throttle queue (`mantisPrefs.setNetworkLimit`, jen HTTP(S)); živé využití přes `mantisPrefs.processStats` (`ChromeUtils.requestProcInfo`); *uvolnit paměť* (`mantisPrefs.minimizeMemory`, jako about:memory → Minimize memory usage; automaticky před uspáváním kvůli limitu, max. 1× za 10 min); *nejnáročnější karty* v nastavení (`mantisPrefs.tabStats` – procesy webů s kartami, paměť + CPU, Uspat/Zavřít); *úsporný režim* `ecoMode` off/battery/on (`mantisPrefs.setEcoMode`: `dom.ipc.processCount` 4, `layout.frame_rate` 60, `browser.sessionstore.interval` 60 s, uspávání po 15 min; „jen na baterii“ přes Battery API okna prohlížeče) |
| `appearance.js` | **Vzhledy a zvuky**: motivy (Kudlanka = výchozí, Noc, Neon, Synthwave, Oceán, Fialka, Západ slunce, Den, **Vlastní** – 5 barev v `themeCustom`) přes `browser.theme` + barva zvýraznění `--mb-accent` na oknech prohlížeče (`mantisPrefs.setAccent`, weby ji nevidí), vlastní barva; **neonová záře** (`themeGlow`, `mantisPrefs.setGlow` → atribut `mantisglow` + `--mb-glow-start`/`--mb-glow`, přechod v `theme/userChrome.css`; barvy `themeGlowColors`: podle pozadí lišty – odstín z její spočítané barvy, i u motivů z AMO, přepočet při změně motivu a světlého/tmavého režimu – nebo dvojice barev motivu); zvuky psaní a karet (`mantisPrefs.setSounds`, posluchač v okně prohlížeče, co se píše, se nečte) – sady generované přes WebAudio (Jemná, Klávesnice, Psací stroj, Bublinky) nebo **vlastní soubory** (`soundCustom`, ≤ 300 kB a 2 s, jen místně). Tapeta nové karty (`newtabWallpaper`, JPEG ≤ 2560 px, jen místně) nastavuje stránka nastavení, zobrazuje `newtab/` |
| `settings/mods.js` | **Mody**: export vzhledu (motiv, barvy, sada a vlastní zvuky, volitelně tapeta) do souboru `.mantis-mod` (JSON) a import. Import přijme jen barvy `#rrggbb`, známé hodnoty, zvuky, které jdou dekódovat (≤ 300 kB, 2 s), a obrázek, který se znovu uloží přes canvas – žádný kód ani CSS; přepínače zvuků nezapíná. Vlastní motiv a vlastní zvuky v Nastavení |
| `otherbrowser.js`, `otherbrowser/` | **Otevřít v jiném prohlížeči** – pro weby, které v Mantisu nefungují (Netflix: licenční server chce podpis Widevine VMP, který mají jen oficiální prohlížeče). Tlačítko v adresním řádku (`page_action`) na webech ze seznamu (výchozí `netflix.com`, `storage.local` → `otherBrowserSites`, synchronizuje se) + jednou za spuštění upozornění; kontextová nabídka stránky, karty a odkazu všude. Prohlížeč: automaticky výchozí prohlížeč Windows (když to není Mantis), nebo zvolený v Nastavení Mantis (`otherBrowser`, jen místně) |
| `tools.js`, `tools/` | **Nástroje** v kontextové nabídce (Nastavení Mantis → Nástroje, každý jde vypnout: `toolUnaccent`, `toolSaveImage`, `toolPrintEdit`, synchronizují se): **Kopírovat bez diakritiky** (výběr, NFD bez značek; zkratka Ctrl+Shift+U – `commands`, oprávnění `clipboardWrite`), **Uložit obrázek do PNG / JPG** (stáhne obrázek, převede přes canvas, i WebP/AVIF/SVG; když pod kliknutím není `<img>`, najde obrázek pod překryvnou vrstvou nebo v `background-image` přes `menus.getTargetElement` + `elementsFromPoint`), **Upravit a uložit PDF** (`tools/print-edit.js` – lišta ve stínovém DOM, kliknutím skrývá prvky, Zpět, skrýt obrázky, zobrazení čtečky, pak `window.print()`) |
| `eshops.js`, `eshops/` | **Varování před rizikovými e-shopy** podle České obchodní inspekce: seznam `eshops/coi-risky.txt` (generuje `scripts/update-eshop-list.sh`, spouštět před vydáním) je v buildu, nic se neposílá. Položka s cestou platí jen pro tu část webu (napadené legitimní weby). Lišta `eshops/warning.js` ve stínovém DOM; „Rozumím, pokračovat“ → `eshopDismissed` (jen místně). Vypínač `eshopWarning` |
| `currency.js` | **Převod měn ve výběru** podle kurzu ČNB (`denni_kurz.txt`, stahuje se jen se zapnutým `currencyConvert`, nejvýš jednou za 6 h → `cnbRates`): „49,99 €“, „$1,234.56“, „USD 120“… → Kč, Kč → EUR; výsledek v kontextové nabídce, kliknutí ho zkopíruje |
| `tabsleep.js` | **Uspávání karet** (`tabs.discard`) po `tabSleepMinutes` (výchozí 60) nečinnosti; neuspí aktivní, připnuté, přehrávající zvuk, ztlumené ani weby z `tabSleepExceptions`; v úsporném režimu nejpozději po 15 min |
| `background.js` | jednou denně zjistí nové vydání Mantisu (`moneyas.cz/mantis/download/latest.json`), volitelně i LibreWolfu; upozornění Windows + proužek na nové kartě. **Podpis vydání**: s veřejným klíčem v buildu (`version.js`, `MANTIS_RELEASE_PUBKEY`) ověří podpis Ed25519 `latest.json` a nepodepsaný ignoruje. **Aktualizace jedním kliknutím** (jen podepsané vydání): stáhne instalátor, ověří SHA-256 z `latest.json` a spustí ho |
| `doh.js` | **šifrované DNS** (DNS over HTTPS, `network.trr.*`): výchozí **vypnuto**; *Automaticky* zapne DoH, jen když síť nezablokuje kanárkovou doménu `use-application-dns.net` (Pi-hole, firemní sítě ji blokují); kontrola při startu, při změně sítě (`networkStatus`) a každých 10 min. Poskytovatelé Quad9, Mullvad, Cloudflare |
| `sync.js` | **synchronizace Nastavení Mantis** přes účet Firefoxu (`storage.sync`): přepínače, DNS, směrování VPN, kill switch. Choulostivé stránky ani VPN profil ne (zůstávají jen v počítači; dřív synchronizované choulostivé stránky se z účtu smažou) |
| `version.js` | verze LibreWolfu, ze které je build – `prepare-source.sh` dosadí `LW_VERSION` místo `@LW_VERSION@` |
| `_locales/`, `i18n.js` | **překlady**: čeština a angličtina (`_locales/cs`, `_locales/en`, výchozí `en` pro ostatní jazyky), jazyk podle prohlížeče (= Windows). Stránky mají jen klíče (`data-i18n`, `data-i18n-html` s povolenými značkami `<b> <i> <code> <br> <a>`, `data-i18n-placeholder/-title/-aria-label`), skripty volají `t("klíč", …)`. Chyby privilegovaného API se překládají přes `context.extension.localizeMessage`, chyby VPN pomocníka posílá pomocník jako kód (`errorCode` → `vpnErr_<kód>`). Kontrola: `node scripts/check-i18n.js` |
| `vpn.js`, `vpn/` | tlačítko VPN ve spodní liště a jeho okno (profil WireGuard, zapnout/vypnout); přepíná proxy prohlížeče, tunel obstarává pomocník z [../vpn](../vpn/README.md). **Směrování**: přes VPN všechno (výchozí), jen vybrané weby/IP rozsahy/kontejnery, nebo všechno kromě nich (`storage.local` → `vpnRouting`). **Kill switch** (`vpnKillSwitch`, výchozí zapnuto): spadlá VPN = zablokovaný provoz místo přímého |

## Vyzkoušení bez buildu

Celé rozšíření **nejde** načíst v obyčejném LibreWolfu přes `about:debugging`:
používá privilegované `experiment_apis` (Nastavení Mantis, Zapomenout web),
které release verze povoluje jen vestavěným rozšířením. Funguje až v buildu.

Samotnou novou kartu nebo okno VPN lze prohlédnout tak, že se z `manifest.json`
dočasně odstraní `experiment_apis` a `forget.js` a doplněk se pak načte přes
`about:debugging` → Tento LibreWolf → **Načíst dočasný doplněk…** (VPN bez
pomocníka ukáže jen hlášku, že pomocník chybí).
